# 🚀 Детальна інструкція для початківців

## Що таке "запустити локально"?

**"Запустити локально"** означає запустити веб-сайт на вашому власному комп'ютері, щоб ви могли:
- Протестувати його перед публікацією в Інтернеті
- Переглянути, як він працює
- Зробити зміни і побачити результат

Коли сайт запущено локально, ви зможете відкрити його у браузері за адресою `http://localhost:3000`, але інші люди в Інтернеті його не побачать. Це як чернетка перед публікацією.

---

## 📋 Частина 1: Запуск локально (на вашому комп'ютері)

### Крок 1: Перевірте, чи встановлено Node.js

Node.js — це програма, яка дозволяє запускати JavaScript-код на комп'ютері (не тільки в браузері).

#### Windows/Mac:
1. Відкрийте термінал (командний рядок):
   - **Windows**: Натисніть `Win + R`, введіть `cmd`, натисніть Enter
   - **Mac**: Натисніть `Cmd + Space`, введіть `Terminal`, натисніть Enter

2. Введіть команду:
   ```bash
   node --version
   ```

3. Якщо ви побачите щось на кшталт `v18.17.0` або `v20.10.0` — чудово, Node.js встановлено! ✅

4. Якщо ви побачите помилку "command not found" або "не є внутрішньою командою":
   - Йдіть на https://nodejs.org/
   - Завантажте версію **LTS** (рекомендована)
   - Встановіть програму (як будь-яку іншу)
   - Перезапустіть термінал і повторіть крок 2

---

### Крок 2: Завантажте код проєкту

Є два способи:

#### Спосіб А: Якщо у вас встановлено Git
```bash
# Перейдіть у папку, де хочете зберегти проєкт (наприклад, Документи)
cd ~/Documents

# Клонуйте репозиторій
git clone https://github.com/ваш-username/ihorsh-tech.git

# Перейдіть у папку проєкту
cd ihorsh-tech

# Перейдіть на нашу гілку
git checkout claude/bible-verse-ai-site-g0dCc
```

#### Спосіб Б: Завантажити ZIP-архів (простіше для початківців)
1. Зайдіть на GitHub: `https://github.com/ваш-username/ihorsh-tech`
2. Натисніть зелену кнопку **Code**
3. Виберіть **Download ZIP**
4. Розпакуйте архів у зручну папку (наприклад, `Документи`)
5. Відкрийте термінал і перейдіть у цю папку:
   ```bash
   cd ~/Documents/ihorsh-tech
   ```

---

### Крок 3: Встановіть залежності

Залежності — це сторонні бібліотеки коду, які використовує наш проєкт (Express, Anthropic SDK тощо).

```bash
npm install
```

**Що відбувається:**
- npm (Node Package Manager) читає файл `package.json`
- Завантажує всі необхідні бібліотеки в папку `node_modules`
- Це займе 10-30 секунд

Ви побачите щось на кшталт:
```
added 120 packages in 5s
```

✅ Це означає успіх!

---

### Крок 4: Отримайте API ключ від Anthropic

Anthropic Claude — це штучний інтелект, який генеруватиме трактування віршів.

#### 4.1 Створіть акаунт
1. Йдіть на: **https://console.anthropic.com/**
2. Натисніть **Sign Up** (або **Log In**, якщо є акаунт)
3. Зареєструйтеся через email або Google

#### 4.2 Отримайте API ключ
1. Після входу натисніть **Settings** (⚙️ налаштування) у верхньому меню
2. Виберіть **API Keys** у лівій панелі
3. Натисніть **Create Key** (Створити ключ)
4. Дайте ключу назву, наприклад: `Bible Verse App`
5. **ВАЖЛИВО:** Скопіюйте ключ і збережіть його! Він виглядає так:
   ```
   sk-ant-api03-ABCDEFGHijklmnop1234567890...
   ```
6. Ви побачите його тільки раз! Збережіть у безпечному місці.

#### 4.3 Додайте кредити (якщо потрібно)
- Нові акаунти отримують $5 безкоштовних кредитів для тестування
- Якщо їх немає, додайте картку в розділі **Billing**

---

### Крок 5: Створіть файл .env

Це файл з секретними налаштуваннями (як пароль від Wi-Fi — зберігається локально).

#### 5.1 У терміналі введіть:
```bash
# Створюємо копію прикладу
cp .env.example .env
```

#### 5.2 Відкрийте файл .env у текстовому редакторі:

**Спосіб 1: Через термінал (для Mac/Linux)**
```bash
nano .env
```

**Спосіб 2: Вручну**
- Знайдіть файл `.env` у папці проєкту
- Відкрийте його в Блокноті (Windows) або TextEdit (Mac)
- **ВАЖЛИВО для Windows:** Переконайтеся, що файл називається `.env`, а не `.env.txt`

#### 5.3 Вставте ваш API ключ:
Файл виглядає так:
```
ANTHROPIC_API_KEY=sk-ant-api03-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
PORT=3000
```

Замініть `sk-ant-api03-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` на ваш справжній ключ:
```
ANTHROPIC_API_KEY=sk-ant-api03-ABCDEFGHijklmnop1234567890...
PORT=3000
```

#### 5.4 Збережіть файл:
- **nano**: Натисніть `Ctrl + X`, потім `Y`, потім `Enter`
- **Блокнот/TextEdit**: `Ctrl + S` (Windows) або `Cmd + S` (Mac)

---

### Крок 6: Запустіть сервер! 🎉

```bash
npm start
```

**Що ви побачите:**
```
> bible-verse-app@1.0.0 start
> node server.js

🌟 Сервер "Щоденне Слово" запущено
📍 http://localhost:3000
📖 Біблійних віршів: 30
```

✅ **Вітаю! Сервер працює!**

### Крок 7: Відкрийте сайт у браузері

1. Відкрийте будь-який браузер (Chrome, Firefox, Safari)
2. У адресному рядку введіть:
   ```
   http://localhost:3000
   ```
3. Натисніть Enter

**Ви побачите:**
- Заголовок "Щоденне Слово"
- Кнопку "Отримати вірш"

4. **Спробуйте натиснути кнопку!**
   - Почнеться завантаження (крутиться індикатор)
   - Через 2-5 секунд з'явиться вірш і трактування від AI

### Крок 8: Зупинка сервера

Коли захочете зупинити сервер:

1. Поверніться до терміналу (де запущено `npm start`)
2. Натисніть **Ctrl + C** (Windows/Mac)
3. Сервер зупиниться

Щоб запустити знову — повторіть `npm start`

## 🌍 Частина 2: Деплой на Render.com (публікація в Інтернет)

Після того, як ви протестували сайт локально, можна опублікувати його, щоб будь-хто міг відкрити за постійною URL-адресою.

### Що таке Render.com?

Render — це хостинг (місце в Інтернеті), де можна безкоштовно розмістити ваш сайт. Це як орендувати квартиру для вашого веб-сайту.

---

### Крок 1: Завантажте код на GitHub (якщо ще не зробили)

#### 1.1 Створіть репозиторій на GitHub
1. Йдіть на **https://github.com/**
2. Увійдіть або створіть акаунт
3. Натисніть **+** (плюс) у верхньому правому куті → **New repository**
4. Заповніть:
   - **Repository name:** `щоденне-слово` (або `bible-verse-app`)
   - **Description:** "Біблійні вірші з AI-трактуванням"
   - **Public** (публічний) ✅
5. Натисніть **Create repository**

#### 1.2 Завантажте код (якщо ви завантажували ZIP)
У терміналі, у папці проєкту:

```bash
# Ініціалізуємо Git (якщо ще не зробили)
git init

# Додаємо всі файли
git add -A

# Створюємо перший коміт
git commit -m "Початкова версія сайту Щоденне Слово"

# Підключаємо до GitHub (замініть YOUR_USERNAME на ваш username)
git remote add origin https://github.com/YOUR_USERNAME/bible-verse-app.git

# Відправляємо код на GitHub
git push -u origin main
```

**Примітка:** Якщо GitHub попросить логін/пароль:
- Використайте Personal Access Token замість пароля
- Створіть його на: https://github.com/settings/tokens

---

### Крок 2: Створіть акаунт на Render.com

1. Йдіть на **https://render.com/**
2. Натисніть **Get Started for Free** (або **Sign Up**)
3. Виберіть **Sign up with GitHub** (простіше!)
4. Авторизуйте Render доступ до GitHub

---

### Крок 3: Створіть новий Web Service

#### 3.1 Натисніть "New +" у верхньому меню
1. На головній сторінці Render натисніть **New +**
2. Виберіть **Web Service**

#### 3.2 Підключіть GitHub репозиторій
1. Render покаже список ваших репозиторіїв
2. Знайдіть `bible-verse-app` (або як ви назвали)
3. Натисніть **Connect** поруч із ним

**Якщо репозиторій не відображається:**
- Натисніть **Configure account** → виберіть репозиторій вручну

---

### Крок 4: Налаштуйте параметри деплою

Render покаже форму налаштувань. Заповніть так:

#### Основні налаштування:
- **Name:** `щоденне-слово` (або будь-яка назва, тільки малі літери і дефіси)
  - Це буде частина URL: `щоденне-слово.onrender.com`

- **Region:** `Frankfurt (EU Central)` (найближче до України)

- **Branch:** `main` (або `claude/bible-verse-ai-site-g0dCc`, якщо працюєте на цій гілці)

- **Root Directory:** залишити пустим

- **Runtime:** `Node` ✅ (повинно визначитися автоматично)

#### Build & Deploy:
- **Build Command:**
  ```
  npm install
  ```

- **Start Command:**
  ```
  npm start
  ```

#### Instance Type:
- **Free** ✅ (безкоштовний план)
  - Обмеження: сервер засинає після 15 хв неактивності
  - Перше завантаження буде повільним (30-60 сек)
  - Достатньо для тестування!

---

### Крок 5: Додайте Environment Variables (секретні налаштування)

**ЦЕ НАЙВАЖЛИВІШИЙ КРОК!**

Прокрутіть вниз до розділу **Environment Variables**.

#### 5.1 Натисніть "Add Environment Variable"

#### 5.2 Додайте API ключ:
- **Key:** `ANTHROPIC_API_KEY`
- **Value:** `sk-ant-api03-ваш-справжній-ключ-тут`

Вставте той самий ключ, який ви використовували в `.env` файлі локально.

#### 5.3 Перевірте ще раз!
- Переконайтеся, що ключ починається з `sk-ant-api03-`
- Не має зайвих пробілів на початку чи в кінці
- Скопійовано повністю

---

### Крок 6: Створіть сервіс і зачекайте деплою

1. Прокрутіть вниз
2. Натисніть велику синю кнопку **Create Web Service**

**Що відбувається далі:**
- Render починає встановлювати залежності (2-3 хв)
- Запускає сервер
- Ви побачите логи в реальному часі:

```

added 120 packages in 15s
Starting server...
🌟 Сервер "Щоденне Слово" запущено
📖 Біблійних віршів: 30
```

3. Зачекайте, поки статус зміниться на **Live** (зелений кружок) ✅

---

### Крок 7: Відкрийте ваш сайт! 🎉

1. Вгорі сторінки Render знайдіть URL вашого сайту:
   ```
   https://щоденне-слово.onrender.com
   ```

2. Натисніть на нього або скопіюйте в браузер

3. **Перше завантаження може зайняти 30-60 секунд** (безкоштовний план)

4. Після цього ви побачите ваш сайт! 🎊

5. **Спробуйте натиснути кнопку** — отримаєте вірш з AI-трактуванням!

## 🐛 Що робити, якщо щось пішло не так?

### Проблема: "Cannot find module 'express'"
**Рішення:** Ви забули виконати `npm install`. Зробіть це у папці проєкту.

---

### Проблема: "Invalid API key"
**Рішення:**
1. Перевірте, чи правильно скопійовано ключ у `.env` (локально) або Environment Variables (Render)
2. Ключ повинен починатися з `sk-ant-api03-`
3. Створіть новий ключ на https://console.anthropic.com/

---

### Проблема: Сервер на Render не запускається
**Рішення:**
1. Перегляньте логи: Render Dashboard → Logs
2. Перевірте Environment Variables (ANTHROPIC_API_KEY)
3. Переконайтеся, що `package.json` містить правильні скрипти

---

### Проблема: "Port already in use" (локально)
**Рішення:**
1. Інша програма використовує порт 3000
2. Зупиніть інший сервер або змініть порт у `.env`:
   ```
   PORT=3001
   ```

---

### Проблема: Сайт працює локально, але не на Render
**Рішення:**
1. Перевірте логи на Render
2. Переконайтеся, що код закомічено і запушено на GitHub:
   ```bash
   git add -A
   git commit -m "Виправлення"
   git push
   ```
3. Render автоматично передеплоїть
